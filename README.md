# 💔 Relaciones Sin Filtro

> *Un espacio de reflexión profunda, análisis y debate abierto sobre la conducta y los vínculos humanos.*

## 🎯 Sobre el proyecto

**Relaciones Sin Filtro** es una página de Facebook dedicada a la creación de contenido visual sobre relaciones de pareja. Aquí compartimos ideas, dinámicas de comportamiento y herramientas prácticas para entender qué pasa detrás de las puertas cerradas en los vínculos amorosos.

Este repositorio contiene el código y los recursos necesarios para generar imágenes de reflexión con headlines impactantes, diseñadas para provocar pensamiento crítico y debate en la comunidad.

## 📚 Contenido

El proyecto trabaja con **250 headlines** organizados en 5 bloques temáticos:

1. **Verdades Incómodas y Banderas Rojas** - Dependencia, manipulación, falta de respeto
2. **Distancia Emocional y Rutina** - Indiferencia, soledad acompañada, apatía
3. **Desamor y Duelo** - Soltar, cerrar ciclos, amor propio tras la ruptura
4. **Intimidad y Conexión** - Sexo, deseo, vulnerabilidad, conexión emocional
5. **Límites y Amor Propio** - Poner fronteras, valor personal, relaciones sanas

## 🛠️ Tecnología

- **Google Apps Script** - Backend para leer datos de Google Sheets
- **HTML/CSS/JavaScript** - Frontend estático (GitHub Pages)
- **html2canvas** - Generación de imágenes PNG desde el DOM
- **Google Sheets** - Base de datos de headlines y desarrollos

## 🎨 Estética visual

- Fondo oscuro (#1a1a1a)
- Acentos dorados (#d4af37)
- Tipografía Georgia (serif)
- Formato 960x720px (proporción 4:3)
- Imágenes optimizadas para Facebook

## 🚀 Cómo usar

1. Configura tu Google Sheet con las columnas: `Headline` | `Desarrollo`
2. Despliega el Apps Script como aplicación web (acceso: Cualquiera)
3. Actualiza la `API_URL` en el `index.html` con tu endpoint
4. Sube los archivos a GitHub Pages
5. Genera imágenes PNG individuales o en lote
